Antideploy deploys apps built anywhere: with Claude Code, Cursor, Codex,
traditional development, or a low-code tool. Bring your project through
GitHub, a folder upload, or an API call. Antideploy reads the code, works out
what it is and what it needs, builds it, and runs it.

You do not describe your app to it. It reads your files and tells you what it
found, with the evidence, before anything is built.

## Using an AI coding agent?

Give your agent this URL. Nothing else, and no credential:

```
https://antideploy.com/llms.txt
```

It explains the whole path from an empty folder to a live URL, and links the
full contract at `https://antideploy.com/api/v1`, which returns endpoints,
request shapes, error codes and limits as JSON. Neither needs a credential to
read.

The agent gets its own. It runs a [terminal login](/api/terminal-login), you
approve one browser prompt, and from then on it creates projects and deploys
them without you copying anything.

<Warning>
Do not paste an API key into a chat window. Anything pasted into a conversation
is in that conversation's transcript for good, and the agent does not need it.
</Warning>

## What Antideploy does not do yet

<Warning>
No object storage, custom domains, background workers, cron jobs, staging
environments, or horizontal scaling. Each app runs on a single instance that
scales to zero.

Antideploy detects when your project needs one of these and tells you at
analysis time, before you deploy, not after.
</Warning>
